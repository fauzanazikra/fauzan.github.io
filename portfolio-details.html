Hotspot Dua Router Mikrotik dengan Web Proxy

Jaringan SMKN 1 Bukittinggi

Proyek akhir ini membangun jaringan hotspot menggunakan dua router Mikrotik, dilengkapi penerapan web proxy untuk mengontrol akses internet pengguna.

Gambaran Proyek

Router pertama berfungsi sebagai gateway internet, sedangkan router kedua mengelola koneksi hotspot dan menerapkan proxy. Pembagian fungsi ini membuat lalu lintas jaringan lebih terstruktur dan mudah dikelola, sehingga cocok untuk lingkungan sekolah atau kantor yang perlu mengawasi penggunaan jaringan.

Poin Penting

  • Koneksi internet melalui DHCP client, serta konfigurasi DNS
  • DHCP server dan jaringan wireless pada kedua router
  • Hotspot dengan halaman login Mikrotik
  • Routing RIP antar kedua router
  • Web proxy dan firewall rule untuk memblokir situs tertentu

Langkah Pengerjaan

  1. Login ke router dan atur alamat IP.
  2. Hubungkan ke internet dengan DHCP client, lalu atur DNS dan firewall.
  3. Buat DHCP server dan jaringan wireless pada router pertama.
  4. Lakukan konfigurasi serupa pada router kedua, lalu buat hotspot beserta nama hotspotnya.
  5. Tambahkan routing RIP pada kedua router.
  6. Hubungkan komputer ke jaringan hotspot, pastikan halaman login Mikrotik muncul, lalu uji ping ke setiap perangkat.
  7. Aktifkan web proxy, cari IP situs target dengan nslookup, lalu buat firewall rule dengan action drop untuk memblokirnya.

Hasil

Penerapan web proxy pada router kedua memberikan kontrol tambahan terhadap akses internet, seperti pembatasan situs, caching data untuk mempercepat akses, dan pencatatan aktivitas pengguna. Dokumentasi lengkap dengan tangkapan layar tiap langkah tersedia di laporan.
